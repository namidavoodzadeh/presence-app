# Package 01: the thinnest version of the whole chain

Confirmed by the owner on 24 Nov 2026. Status: scope set, contents not yet written, not frozen.

The app is useless without knowledge about the person, so the first package covers the full chain once, as thin as it can be while working end to end:

1. Sign-in.
2. A first Talk conversation, led by the engine: short, welcoming, motivating.
3. "What I learned about you", shown simply, so the person sees the knowledge forming and trusts it.
4. Write with insight, drawing on that knowledge. Insight on wording alone must already help when little is known.
5. Send, and the other person reads it.

Not in package 01: import from your AI, scheduled sends, check-ins, receiving-side insight, the map, cards, Mirror.

## Order after this
- Package 02: import from your AI, returning for more Talk sessions, scheduled sends and check-ins.
- Package 03: insight on the receiving side.
- Package 04: the map, cards and Mirror.

## Product core, in the owner's words (24 Nov 2026)
Words are not all that is transferred. Sender and receiver each read a message inside their own thoughts, mood and beliefs.
General AI assistants know one person, and see everyone else only through that person's eyes. This app covers that gap.
Everything beyond that core is secondary.
