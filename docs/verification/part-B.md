## Package gaps, simplest behaviour taken
- **"The four numbers" (B6, merge policy) were not defined anywhere.** Taken as: flaw caught (higher is better), false alarms (lower), belief link right (higher), receiver reading match (higher). Compared as rates. Change in `evals/bridge_offline/compare.ts` if the psychology advisor names others.
- **One shared concurrency group vs "one at a time per track" (B5).** The shared group is stricter and satisfies both. GitHub keeps only one *pending* run per group, so a third run queued behind a running and a pending one cancels the pending one. A single runner would already serialise jobs without that loss. If cancelled runs show up, drop the shared group and rely on the one runner.
- **Review model family (B4).** No provider was named. The script calls any OpenAI-compatible endpoint set in repository variables. It fails closed until configured.
- **Contract generation** is ahead-of-time (see `part-A-mac.md`), so CI runs `generate.sh --check` as contract validation.
- `build-item.yml` starts only when the repository owner adds `ready`, because the repository is public and issue text reaches a coding session on the Mac.
- Fork pull requests: workflows skip jobs from forks, and the repository now requires approval for workflow runs from all outside contributors.
